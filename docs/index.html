Underlist

Finds underpriced listings for the stuff you flip.
Get the extension
The current build and install guide are pinned in the Discord — grab the zip from #releases.
Open the Discord → #releases Project on GitHub
Install (2 minutes)
1. Unzip. Put the underlist folder somewhere permanent — not Downloads.
2. Go to chrome://extensions, turn on Developer mode (top right).
3. Load unpacked → pick the underlist folder. Setup opens — pin the icon.
Sign in to Facebook first. Underlist reads the Marketplace pages you open — logged out, Marketplace shows nothing and there's nothing to score.
Your license key: open your purchase → Manage membership → Underlist → Software. Paste it in Settings → AI → License key.
